     Server backup
    
      
    
        
    Websites (/home), system files (/etc, cron, OpenLiteSpeed config), CyberPanel settings and every MariaDB database, one dump per database so one website can be restored alone. Runs in the nightly job after the Docker backups and is copied to the NAS (folder _server).

     Nightly job
    
      
    
        
    
          
    
            
    
            
    
            
    
          
    
          
    Old backups are removed only after a run and never below the “always keep” number, so a broken job cannot delete your last good copies. Local folder: /var/backups/docker/<container>/.
    
          
    
        
    
        
    What the nightly job does
      
      
      
    
      
  
      

  
      
    
      
      
       Copy to a NAS or another server
      
      
      
        
      
          
      
          
      
          
      
          
      
          
      
          
      
          
      
        
      
        
      
          
      VPN configuration
      
          
      Upload the client file from your VPN server (.conf for WireGuard, .ovpn for OpenVPN). It is stored readable by root only. The VPN connects only for the copy and only traffic to the NAS goes through it, so access to this server is never cut off.
      
          
      
          
      
        
      
        
      SSH key
      
        
      The panel logs in with a key, no password is stored. Install key asks for the NAS password once, uses it to install the key and forgets it. Or paste the public key into the NAS user's ~/.ssh/authorized_keys yourself. The NAS needs SSH and rsync (Synology: Control Panel > Terminal and SNMP > SSH, and File Services > rsync).
